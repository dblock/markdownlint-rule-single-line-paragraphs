# Contributor Instructions

- Keep the custom rule implementation in `index.cjs` compatible with Node.js 22 and later.
- Add or update tests in `test/single-line-paragraphs.test.mjs` for every behavior change.
- Run `npm test` before committing.
- Document user-visible changes in the `(Next)` section of `CHANGELOG.md`.
- Keep Markdown prose on one source line unless an intentional hard break is required.
