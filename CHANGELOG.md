### 0.1.0 (2026/10/07)

* Initial public release - [@dblock](https://github.com/dblock).
* Added a markdownlint custom rule that requires each prose paragraph to use one source line - [@dblock](https://github.com/dblock).
* Added support for paragraphs at the document root and inside lists and blockquotes - [@dblock](https://github.com/dblock).
* Added automatic fixes that join continuation text and remove the original continuation lines - [@dblock](https://github.com/dblock).
* Preserved explicit Markdown hard breaks created by trailing spaces or an unescaped backslash - [@dblock](https://github.com/dblock).
* Preserved `<br>`, `<br/>`, and `<br />` tags at the beginning or end of a source line - [@dblock](https://github.com/dblock).
* Excluded headings, code blocks, tables, HTML blocks, front matter, and definitions - [@dblock](https://github.com/dblock).
* Added continuous integration for Node.js 22 and 24 and npm publishing with provenance - [@dblock](https://github.com/dblock).
